## 한계 — 반드시 함께 보고한다

1. **표본 2명 · 세션 4회.** 25절이 요구한 3~5명에 못 미친다
2. **두 사람 다 이 도구를 만든 사람이다.** 자기평가 편향이 있다
3. **언어 교란이 있다.** 대상 저장소는 영어, Re:Code 리포트는 한글이다.
   A 조건 사용 의향 1점에는 **도구 부재가 아니라 영어 장벽**이 섞여 있다.
   → **A/B 격차가 실제 도구 효과보다 부풀려져 있을 수 있다**
4. A 조건에서 두 사람 다 파일 수준(`validator.py`, `after.py`)까지만 짚었고
   함수 수준까지 특정하지 못했다. B 조건은 `파일:줄` 까지 제시됐다
5. **통계적 유의성을 주장하지 않는다** (25절)
