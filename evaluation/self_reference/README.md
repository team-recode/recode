- `scripts/run_validation.py:60` → `raise SystemExit(...)`, 모듈 상단에서 `genai` import

**답**: 의도했다. `scripts/` 는 CLI 전용이라 `SystemExit` 로 바로 끝내는 게 맞고,

**중복 자체는 의도적** — 제품 코드(`judge/`)가 검증 도구(`scripts/`)에 의존하면 레이어가 뒤집히므로 일부러 복제했다(PHASE 6 기록).
